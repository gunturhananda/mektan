# Perhitungan Anggota Kelompok 7 — Praktikum Mekanika Tanah UNJA

Website perhitungan otomatis 1:1 sesuai laporan Praktikum Mekanika Tanah Kelompok 7 (Teknik Sipil, Universitas Jambi) lengkap dengan input NIM dinamis, 13 langkah perhitungan 1:1 (termasuk 55 data Sondir 0,00–10,80 m), 19 form resmi berlogo UNJA + 9 sheet grafik native Excel (`.xlsx`), dan tampilan ramah HP.

## Cara Upload ke GitHub Pages (`github.io`)
1. Ekstrak file ZIP ini, lalu buat repository baru (Public) di GitHub.
2. Unggah seluruh isi folder (`index.html`, `.nojekyll`, `README.md`) ke branch `main`.
3. Buka **Settings → Pages → Build and deployment → Source: Deploy from a branch**, pilih branch `main` folder `/ (root)`, lalu klik **Save**.
4. Tunggu 1–2 menit, website langsung aktif di alamat `https://<username>.github.io/<nama-repo>/`.
